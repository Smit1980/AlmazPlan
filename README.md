# AlmazPlan

Публичная страница концепции сюжетной игры «Алмазный огранщик».

Проект находится на этапе описания идеи и подготовки первого проверяемого эпизода. Указанные объём, механика и дорожная карта — рабочие предложения для оценки и тестирования.

Рабочие документы хранятся отдельно в [папке Google Диска](https://drive.google.com/drive/folders/1YqOOoHH0xIDIaRwoHlPaixi5fuxLbT6V). Доступ к папке предоставляется участникам команды отдельно.

Сайт статический: откройте `index.html` или запустите локальный HTTP-сервер в этой папке. Изображение героя страницы создано для этого проекта.
